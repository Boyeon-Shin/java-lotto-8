# java-lotto-precourse

## 기능 목록

### 입력 기능
- [x] 로또 구입 금액을 입력받는다.
    - [x] 1,000원 단위로 입력받는다.
    - [x] 1,000원으로 나누어 떨어지지 않으면 예외 처리한다.
- [x] 당첨 번호를 입력받는다.
    - [x] 쉼표(,)를 기준으로 구분한다.
    - [x] 6개의 번호를 입력받는다.
    - [x] 1~45 범위의 숫자인지 검증한다.
    - [x] 중복되지 않는 숫자인지 검증한다.
- [x] 보너스 번호를 입력받는다.
    - [x] 1~45 범위의 숫자인지 검증한다.
    - [x] 당첨 번호와 중복되지 않는지 검증한다.

### 로또 발행 기능
- [x] 구입 금액에 따라 로또를 발행한다.
- [x] 로또 번호는 1~45 범위의 중복되지 않는 6개의 숫자로 구성된다.
- [x] 발행된 로또 번호를 오름차순으로 정렬한다.

### 당첨 확인 기능
- [x] 당첨 번호와 구매한 로또 번호를 비교한다.
- [x] 일치하는 번호의 개수를 확인한다.
- [x] 보너스 번호 일치 여부를 확인한다.
- [x] 당첨 등수를 판단한다.
    - [x] 1등: 6개 번호 일치 / 2,000,000,000원
    - [x] 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
    - [x] 3등: 5개 번호 일치 / 1,500,000원
    - [x] 4등: 4개 번호 일치 / 50,000원
    - [x] 5등: 3개 번호 일치 / 5,000원

### 결과 출력 기능
- [x] 발행한 로또 수량과 번호를 출력한다.
- [x] 당첨 내역을 출력한다.
- [x] 총 수익률을 계산하여 출력한다.
    - [x] 수익률은 소수점 둘째 자리에서 반올림한다.

### 예외 처리
- [x] 잘못된 값 입력 시 `IllegalArgumentException`을 발생시킨다.
- [x] 에러 메시지는 "[ERROR]"로 시작한다.
- [x] 에러 발생 시 해당 부분부터 입력을 다시 받는다.
